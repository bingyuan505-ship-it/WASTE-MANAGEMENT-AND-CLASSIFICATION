# WASTE-MANAGEMENT-AND-CLASSIFICATION
Waste Classification System uses transfer learning to classify plastic, metal, and glass waste. ResNet50, MobileNetV2, and VGG16 were evaluated, with ResNet50. The project demonstrates the potential of AI-based waste sorting for smart recycling applications.
